## 失败案例A：元宇宙土地泡沫破裂（2021→2024归零）

## 场景
客户持有/推荐购买 Decentraland / Sandbox / Otherside 元宇宙虚拟土地

## 背景
- 2021年11月：Decentraland 土地均价 $3.5万，Sandbox 土地 $1.2万
- 2022年初：Meta 改名引爆 FOMO，Otherside 土地销售 $3.7亿
- 2024年：元宇宙土地地板价平均跌 98.5%，Decentraland 日活<千

## 决策流（错误决策回放）

### 第1步：入场动机判断
```
用户：「元宇宙是未来，Facebook都改名了」
模型判断：→ 趋势投资 → 允许入场
```

### 第2步：价值评估
```
模型评估：
- 有知名项目方 ✅
- 有土地稀缺性 ✅  
- 有大厂背书 ✅
- → 被判为合理投资
```

### 第3步：调仓规则
```
每下跌20%加仓一次：
- 从$3.5万→$2.8万→$2.2万→$1.8万→$1.4万→$1.1万→$8800→$7000
- 最终仓位失控，占总资产35%
```

## 失败归因（真正的为什么错）

| 维度 | 当时判断 | 实际真相 | 错在哪 |
|------|----------|----------|--------|
| 需求本质 | 社交+商业地产需求 | 投机需求，无实用场景 | 把一次性FOMO当成长久需求 |
| 稀缺性 | 土地总量有限 | 有需求才有稀缺，需求消失=无限供给 | 误判稀缺性前提 |
| 护城河 | 品牌认知+开发者生态 | 用户可零成本切换 | 黏性远低估 |
| 日活/土地比 | 没关注 | 0.07人/地块 | 关键指标遗漏 |
| 商业化 | 广告+活动租赁 | 无可持续收入模型 | 估值没有现金流基础 |

## 失败原因链
```
FOMO入场 → 未拆分投机 vs 投资 → 未设日活底线指标 → 
下跌仅看"打折"而非"逻辑失效" → 倒金字塔加仓 → 
仓位失控 → 最大亏损-98%
```

## 什么样的NFT能存活10年？（反推成功标准）
1. **有实际现金流产生**（版权分润/流动性挖矿/真实收益）
2. **持有人留存率≥70%/年**（不是一次性购买）
3. **项目方运营≥4年**（穿越牛熊）
4. **至少1轮熊市中地板价回撤<60%**（强于大盘）
5. **商业化≥3个独立收入源**

## 失败边界
- 此案例适用于：任何"虚拟世界/元宇宙"类型NFT
- 不适用于：有实际实体经济锚定的数字资产（如RWA）
- 成功率：元宇宙土地长期存活率 < 0.1%

## 失败案例B：PFP蓝筹（BAYC/Azuki）腰斩失误

## 场景
2022年5月客户问：「BAYC从$40万跌到$25万，是不是抄底机会？」

## 决策流（错误判断版本）
```
1. BAYC是蓝筹 ✅
2. 从高点跌了37% → 深度回调 ✅
3. 社区活跃度还行 ✅
4. Yuga Labs融资$4.5亿 ✅
→ 建议抄底
```

## 实际结果
- BAYC 2024年地板：$3.2万 → 再跌87%
- 深度回调判断错误：把半山腰当底

## 归因
| 判断错误 | 正确做法 |
|---------|---------|
| 只看价格跌了多少 | 还要看成交量腰斩多少（流动性枯竭） |
| 只看了社区活跃度 | 没看新增用户留存率（全是存量互割） |
| 只看融资额 | 没看融资轮次估值=最后一次接盘价 |
| 把股票回调逻辑套到NFT | NFT流动性差10倍，底部更难判断 |

## 正确决策路径
```
1. 先看持有人留存率 → 低于70% → 不买
2. 再看月新增买入vs卖出 → 卖出>买入 → 不买
3. 再看项目运营状态 → 团队隐身/裁员 → 不买
4. 最后看大盘 → 整体NFT交易量跌90%+ → 不买
→ 结论：BAYC不是机会，是半山腰的陷阱
```

## 失败边界
- 此案例适用于：所有PFP/Avatar类NFT
- 不适用于：有真实资产锚定或现金流产生的数字资产
- 关键指标：NFT用"深度回调"策略的胜率<15%，远低于A股

## 失败案例C：链游代币（StepN/Splinterlands）死亡螺旋

## 场景
2022年StepN GST从$0.5涨到$4，客户问「跑步赚钱是真的吗？」

## 失败归因
| 信号 | 问题 |
|------|------|
| 代币无限增发 | 每跑一步就增发，有下限无上限 |
| 单一收入模型 | 只有租赁/赚币，没有销毁场景 |
| 用户增长 = 供给 | 新用户越多，抛压越大 |
| 经济学失败 | 赚钱效应吸引的是投机者不是跑者 |

## 铁律
- 链游代币不要用时价/基本面分析
- 必须走**代币经济学四问**：
  1. 增发速度 vs 销毁速度？
  2. 有多少真实消费场景？
  3. 玩家留存率30天多少？
  4. 项目方钱包地址有多少未售代币？

## 适用边界
- 任何Play-to-Earn模型 → 平均寿命3-8个月
- Move-to-Earn模型 → 平均寿命4-6个月
- 唯一例外：代币有刚性消费场景+限时销毁机制
