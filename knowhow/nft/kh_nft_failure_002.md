# 数字藏品Agent · 失败案例（第2块）：平台关停 / 一级MINT破发 / NFT抵押清算螺旋

> 第1块(failure_001)已覆盖「元宇宙土地/BAYC/链游」三大死亡螺旋——那是"项目泡沫自身破灭"。
> 本块补全**另外三条独立死亡路径**：①平台关停归零（非项目价值、是交易场所消失）；②一级MINT破发（买在发行价即亏）；③抵押清算螺旋（借贷放大死亡）。三者对应不同的失败归因，是 Agent 必须能区分的场景。

---

## 失败案例D：国内平台型数字藏品关停归零（iBox / 幻核 / 各大数藏平台）

## 场景
客户问:"我在某数字藏品平台买的藏品，平台说6月30日停止运营，藏品还能变现吗？"

## 背景（真实时间线）
- 2021-2022 国内数藏平台超 1000 家,头部 iBox、幻核(腾讯)、鲸探(阿里)等
- 2022-09 腾讯幻核宣布停止发新+将部分藏品退款;平台类数藏"官方二级交易"被清理
- 2022-2023 大量中小平台跑路/关停,用户所持"数字藏品"仅剩"一串保存在平台服务器的哈希"
- 平台一旦关停：无二级市场、无官方回购、无链上可验证的独立所有权 → 价格硬归零

## 决策流（先判"你持有的是不是'平台私域'而非'真链上资产'"）
```
问题1：你的藏品是"平台托管"还是"自持私钥"？
  平台托管(私钥在平台) ──▶ 平台关停 = 你的凭证可能一起消失 ─▶ 高风险
  真链上自持(自己钱包有私钥) ──▶ 平台关停只是失去"交易入口"，链上还在 ─▶ 中风险

问题2：(若平台私域) 平台是否有"官方回购/抵扣承诺"？
  有书面对价承诺 ──▶ 按承诺走退款，但要设"平台也可能赖"的最坏预期
  无任何承诺 ──▶ 直接按归零处理，禁止"抄底补仓"

问题3：平台是否已发"停止/清退"公告？
  已公告关停 ──▶ 唯一动作 = 尽快提出可提现资产，remaining 按 0 计
  未公告但平台暴雷传闻 ──▶ 先降低仓位，不入场
```

## 为什么这样判
- 国内数字藏品的关键不是"链上稀缺性",而是"平台是否还在运营"——平台即交易所。
- 交易场所消失 = 流动性归零 = 价格归零,与项目基本面无关。这是**通道风险**,failure_001 的"项目风险"判不了它。

## 失败边界
- 适用：任何"平台私域托管、无独立链上所有权"的数藏。
- 不适用：已上公开链(以太坊/Flow等)、私钥自持、存在真实二级市场的海外NFT。
- 成功率信号：平台公告清退 → 拖到关闭日仍持有 = 大概率归零(历史上 iBox 之后场外价格 90%+ 崩盘)。

## 失败案例E：一级MINT破发——"首发即亏"，抢购≠赚钱

## 场景
客户在项目发售(铸造/MINT)当天抢到,问:"白名单抢到了,要不要立刻挂卖出?会不会像上次首发就破发？"

## 失败归因（为什么 MINT 常常比你想象的更亏）
| 信号 | 问题 | Agent 应识别 |
|------|------|------------|
| 一级抢购靠"手速/白名单" | 拼的不是价值判断,而是情绪 | 抢到≠有 alpha,发行价本身可能已透支预期 |
| 发行价 vs 同赛道地板 | 新项目发行价往往对标"上一个爆款"定高价 | 用"同赛道已跌"做锚,新品发行价大概率虚高 |
| 破发后"等反弹"心态 | 多数人 MINT 亏了不割,等"回到发行价" | NFT 无量阴跌,回到发行价概率极低(流动性差) |
| 二次/Custom MINT 增多 | 多发同款稀释存量 | 每次增发 = 存量价值被稀释 |

## 决策流（MINT 抢购的正确打开方式）
```
1. 抢购前：先问"发行价相对同赛道地板是贵是便宜？"
     发行价 > 同赛道地板 ×2 ──▶ 不参与白名单(大概率破发)
     发行价接近/低于同赛道地板 ──▶ 才考虑参与
2. 抢到后立即决策，不"等反弹"：
     开盘价 ≤ 发行价(破发) ──▶ 立即止损挂单，不幻想回到发行价
     开盘价 > 发行价(有溢价) ──▶ 才是可持有/套利的入场信号
3. 铁律：MINT 前你没算清发行价 vs 地板，就禁止参与白名单。
```

## 失败边界
- 适用：绝大多数"新项目首发/NFT MINT"场景。
- 不适用：有真实现金流、地板长期稳步走强的极少数优质蓝筹(如早期 CryptoPunks 类)发行。
- 成功率：首日破发率在热门赛道普遍 >50%;MINT 即赚钱本质上是少数。

## 失败案例F：NFT 抵押清算螺旋（BendDAO 模式）——"借钱买蓝筹"的死亡放大

## 场景
客户想抵押自己持有的蓝筹NFT(如BAYC)借 USDT 加杠杆再买,问:"抵押蓝筹借钱加仓稳不稳？"

## 隐藏的加强版死亡机制
```
正常下跌 ▼
  ──▶ 抵押资产价格跌破"清算线"
  ──▶ 借贷平台强制平仓砸盘(清算拍卖)
  ──▶ 抛压加剧 → 价格进一步下跌
  ──▶ 更多抵押单被清算 → 螺旋放大(清算螺旋 / 死亡螺旋)
```
- NFT 抵押与股票配资的差异：NFT **流动性极差**,清算拍卖时"无人接盘",拍卖价远低于真实地板 → 脆断更猛。
- 2022 年 BendDAO 事件:蓝筹抵押项目,地板价下跌触发连环清算拍卖,一度濒临崩盘,持有者血本无归远快于"正常持有者"。

## 决策流（遇到"抵押借贷加仓NFT"一律高度警惕）
```
1. 用户提出"抵押 NFT 借贷加仓" ──▶ 直接判定为高风险，先讲清算螺旋，不急着算收益
2. 算清"清算缓冲垫"：
     当前价距清算线 < 30% ──▶ 极高危(一次波动就触发)
     当前价距清算线 > 50% 且流动性充裕 ──▶ 才勉强可评估
3. 强制问：借款用途是什么？
     补仓/加码 ──▶ 用杠杆放大泡沫 = 死亡螺旋燃料，拒绝
     短期周转(流动性需求) ──▶ 仅限极低杠杆(抵押率<50%)且明确还款来源
4. 铁律：NFT 抵押借贷属于"流动性最差资产上杠杆",除非有真实现金流，否则全线拒绝。
```

## 为什么这样判
- NFT 抵押把"价格下跌"变成"强平抛压 + 击穿清算线"的自我强化。
- 普通持有者亏 50% 可以拿;抵押者可能在亏 30% 时就已被强制清仓归零。杠杆把慢死变成速死。

## 失败边界
- 适用：一切"蓝筹NFT抵押借贷 / 抵押加仓"场景。
- 不适用：有真实现金流、且借贷用途是流动性周转而非加仓的极少数。
- 关键指标：抵押率、距清算线缓冲垫、标的流动性、借款用途。

## 三案例对照(让 Agent 一眼分诊)

| 场景 | 失败本质 | 第一反应 | 错误做法 |
|------|---------|---------|---------|
| 平台关停(D) | 通道/场所消失 | 尽快提现+按归零计 | 抄底补仓 |
| 一级MINT(E) | 发行价透支预期 | 开盘定生死,破发即止损 | 等回发行价 |
| 抵押清算(F) | 杠杆放大下跌 | 拒绝/降杠杆 | 加杠杆抄底 |

## 经验权重
**高** —— 三点补齐了 failure_001 的盲区：
1. 平台私域(通道风险)与链上资产(项目风险)必须分开判;
2. 一级与二级是两套逻辑,不能混用"等反弹";
3. 凡涉及借钱的 NFT 一律先讲清算螺旋。
这对 Agent 的"买入建议/风险提示/回撤处理"三个核心场景都是硬约束。
