## 数字藏品Agent — 专家判断决策路径（"为什么这样判断"）

> 本砖回答的不是"买什么"，而是**专家在收到一个数字藏品问题时，脑子里实际走的那条推理链**。
> 与 rules_nft_001（业务规则：评分+配置）互补：rules 给"标准答案"，本砖给"推理与例外"。

## 场景
用户提出任何数字藏品/NFT 问题：买入、持有、回撤处理、项目评估、"还能不能拿"、"要不要加仓"。

## 输入
- 项目名、地板价、历史走势
- 持有人数、日活、成交量变化
- 运营状态、官方公告、社区活跃度
- 用户当前仓位占比（是否超 10% 铁律）

## 决策流（专家完整推理链）

### 第0步：先分类问题 → 决定用哪条子路径
```
用户问题是什么类型？
1. 买入（新项目/加仓）→ 走【买入决策流】
2. 持有/回撤处理 → 走【持有/卖出决策流】
3. "今天买什么"提问 → ❌直接拒绝，不回答
```

### 第1步：赛道硬过滤（一句话决定生死，不做任何评分）
```
把项目丢进两桶：
- 长期桶：AI数字资产 / RWA / BTC生态 / 蓝筹NFT
- 死亡桶：元宇宙土地 / 纯艺术NFT / 链游装备

落入死亡桶 → 无论价格多便宜、热度多高 → 直接拒绝。
为什么？见 kh_nft_failure_001：这三类 5 年存活率 <0.1-3%，FOMO 只是泡沫燃料。

例外：死亡桶项目 ONLY 当我被明确要求做"风险归因分析"（不是买入建议）时才进入，且只讲为什么它会死，绝不建议持有。
```

### 第2步：买入决策流（仅长期桶项目进入）
```
输入：长期桶某项目

判断A：先算"生存证据"，不是算"涨多高"
  1. 穿越牛熊？(历史≥4年经历过≥1轮熊市)
  2. 商业化≥3个独立收入源？
  3. 项目方运营≥3年且团队在岗？
  4. 持有人留存率≥70%/年？(非今日新增)

  生存证据 <2项 → ❌ 不管评分多高，不买。可能只是"看起来蓝筹"的接盘陷阱。
  生存证据 ≥2项 → 进入评分体系(rules_nft_001：稀缺30/合规25/流动性25/长期共识20)

判断B：稀缺性审查（最容易自欺的一环）
  问："稀缺"是相对需求而言的吗？
  - 有需求才有稀缺 → 需求消失=无限供给（元宇宙土地陷阱）
  - 只看总量有限而忽视需求 → 是误判
  例外：真实资产锚定/现金流支撑的稀缺（RWA）可豁免此审查。

判断C：合规审查
  - 是国内项目？→ ❌国内二级市场不参与（违规，铁律）
  - 海外合规项目 → 继续

判断D：仓位判定
  得分结果 → 按 rules_nft_001 分仓：
  数字茅台6项全中 → 核心仓 60%
  高分但未全中   → 成长仓 30%
  验证逻辑       → 观察仓 10%
```
### 第3步：持有/回撤决策流（卖出侧，与买入侧互补）
```
场景：已持有，项目下跌或停更

判断1：下跌归因——先问"是打折还是逻辑失效？"（这是专家与散户的分水岭）
  触发线：地板价-50% 或 项目停更90天
  深挖逻辑（不自动卖）：
  a. 持有人留存率是否还≥70%？  —下降→逻辑在坏
  b. 成交量是否腰斩？          —腰斩→流动性枯竭(蓝筹陷阱)
  c. 月新增买入 vs 卖出        —卖出>买入→存量互割
  d. 团队是否隐身/裁员         —是→运营失效
  e. 用户增长的来源            —投机者涌入→死亡螺旋前兆

  逻辑仍健康（b/c/d 都没坏）→ 🟡持有观察，不因为跌了50%恐慌。
  逻辑已失效（1项以上坏且恶化）→ 🔴淘汰，看逻辑不看短期价格。

判断2：仓位再平衡
  单一资产>组合10% → 强制减仓（铁律，无例外）

判断3：加仓审批
  用户想加仓摊平 → 走完整【买入决策流】重新评估。
  例外：如果逻辑已失效，禁止"越低越买"（倒金字塔=失败案例A的病根）。
```

## 为什么这样判断（专家推理的解释）
1. **先过滤后评分**：评分体系容易让人为"高分垃圾"找理由。先赛道过滤守住了第一道门，避免 FOMO 进入评分器。
2. **买的是"生存证明"不是"上涨幅度"**：NFT 无现金流锚定，唯一可靠的长期信号是"它活了多久、留住了多少人"。增长快可能只是投机脉冲。
3. **回撤先归因**：股票回调逻辑不能直接套 NFT——NFT 流动性差 10 倍，底部难判断（蓝筹失败案例 B）。所以先问逻辑是否失效，而不是看跌了多少。
4. **卖上看量**：持有人留存率 + 成交量变化，比价格更能提前暴露 death spiral。

## 例外处理（全部决策流的 SPA 点）
- 条件(赛道分类)无法判定 → 按"未知"归入保守桶，不买入，等待更多证据。
- 稀缺性数据缺失 → 用日活/地块比或持有人留存率兜底，不因数据缺失放行。
- 用户只给"热度高"作理由 → 拒绝，要求补充生存证据。
- 用户情绪化("跌这么多快帮我") → 先安抚并归因，禁止用加仓/砍仓的恐慌操作应对。
- 观察仓逻辑验证失败 → 止损出局，不进成长仓。

## 失败边界
- 本决策流适用于：数字藏品/NFT 的买入、持有、回撤、项目评估。
- 不适用于：交易所流通的数字证券、有稳定现金流的 RWA 债权类（走向不同估值逻辑）。
- 不适用于：用户明确做短线/打板/情绪炒作（V6.0 铁律：颠覆设计不支持短线）。
- 成功率：坚持赛道过滤+生存证据，可把"接盘死亡螺旋"概率降到可忽略；但**无法预测短期涨跌**，本流程只为 5-10 年存活服务。
- 已知缺陷：对"伪 RWA"（真实资产但估值被情绪推高）识别仍依赖人工尽调，无法纯自动化判断资产真实性。
