## 期货风控与交易业务规则（期货侧第一块）

> 与 kh_stock_rules_001（股票买入侧）、kh_stock_rules_002（股票卖出侧）互补。**股票亏的是本金，期货亏的是保证金+负债——规则差异的核心：股票靠"止损纪律"管风险，期货靠"仓位=保证金占比"管风险，杠杆让一次判断失误的代价放大10倍，所以期货侧的第一规则是仓位规则，不是方向规则。**

## 场景
- Research OS 中涉及期货品种（黑色/化工/农产品/有色/贵金属/能源/股指国债）的研究或交易建议
- 用户持有期货仓位（日内/隔夜）时的每日风控巡检
- 节假日（春节/五一/十一）前的持仓检查
- 极端行情（涨跌停/单边市）下的应急决策

## 输入
1. 品种所在交易所保证金比例（交易所会临时调整，需查当日值）
2. 合约乘数、当前价格 → 合约价值 = 价格 × 乘数
3. 账户权益、已用保证金、可用资金
4. 持仓品种的涨跌停板幅度（交易所公布，连续涨跌停会扩板）
5. 节假日安排（交易所节假日保证金/涨跌停调整通知）

## 决策流

### A. 仓位计算铁律（先算仓位，再谈方向）
```
1. 计算合约价值 = 当前价格 × 合约乘数
   （螺纹10吨/手、豆粕10吨/手、铜5吨/手、原油1000桶/手、股指300元/点）
2. 计算单手持仓保证金 = 合约价值 × 保证金比例
   （交易所基准：螺纹13%、豆粕10%、铜12%、原油15%、IF股指12-15%）
3. 投机仓位铁律：
   单品种占用保证金 ≤ 总权益 × 20%
   全部品种占用保证金合计 ≤ 总权益 × 50%
4. 实际杠杆 = 全部合约价值 ÷ 总权益
   杠杆 > 3倍 → 强制降仓（投机单）
   杠杆 > 5倍 → 无条件砍仓最重品种（无论方向对错）
5. 套保单（有现货/订单对冲）杠杆可放宽至 5-8 倍，但必须标注"套保"身份
```

### B. 保证金与强平监控（每日必检）
```
1. 权益 < 维持保证金（通常=初始保证金的80%）→ 触发追保警告
   → 12小时内未补足或未减仓 → 期货公司强平
2. 强平顺序（期货公司默认）：
   平亏损最大的 → 平流动性最好的（避免平不掉） → 平保证金占用高的
3. 穿仓红线：权益 < 0
   国内规则：期货公司先行垫付→向客户追偿，不允许账户穿仓挂账
   结论：**杠杆单永远留足"补保证金 buffer"（至少10%总权益现金）**
4. 每日 15:00 收盘后 + 夜盘开盘前 各做一次保证金试算
```

### C. 隔夜与节假日规则（跳空风险）
```
1. 隔夜单：允许，但单品种隔夜保证金占用 ≤ 总权益 × 15%
2. 节假日（春节/五一/十一）前 3 天交易所上调保证金比例（通常+3~5个百分点）
   → 触发条件：距离假期 ≤ 3 个交易日
   → 决策：权益缓冲不足（可用资金 < 总权益10%）→ 节前降仓或清仓
   → 长假原则：不留重仓过夜，除非有现货对冲（套保身份）
3. 涨跌停扩板规则：连续涨跌停会扩板
   第1次停板：按原幅度停 → 第2日扩板（如6%→9%） → 第3日继续扩
   含义：亏损不是"今天亏6%就完"，可能是"明天再亏9%"——第一日跌停必须第一时间处理，不能赌次日开板
```

### D. 极端行情应急（涨跌停封死/单边市）
```
1. 持仓反向封死跌停（卖不出）：
   → 立即评估跳空风险：次日大概率低开 → 挂跌停价排队平仓（不撤单）
   → 同时减其他品种腾保证金，防止连环强平
2. 连续跌停无法平仓时：
   → 禁止"加仓摊薄"（期货加仓摊薄=自杀，保证金占用翻倍，强平线更近）
   → 唯一动作：等待开板第一时间平仓 + 准备穿仓预案（补保证金）
3. 交易所临时风控（涨跌停板扩大/暂停交易/调整保证金）→ 按交易所公告执行，不臆测
```

### E. 品种分组与相关性规则（Research OS 特供）
```
1. 品种分组（研究时同组内只取最强/最弱代表，不重复覆盖）：
   黑色系：螺纹/热卷/铁矿/焦炭/焦煤（地产基建周期驱动）
   化工系：PTA/甲醇/塑料/PP/乙二醇（原油+产能周期驱动）
   农产品：豆粕/豆油/玉米/白糖/棉花（供需季+天气驱动，有季节性）
   有色系：铜/铝/锌/镍（全球宏观+美元驱动）
   贵金属：沪金/沪银（避险+实际利率驱动，与股债负相关）
   能源系：原油/燃油/沥青（地缘+库存驱动）
   金融系：IF/IH/IC/IM股指 + 国债期货（权益/利率驱动）
2. 同组品种方向一致时 = 组内共振，信号可信度 +20%
3. 跨组对冲（螺纹多 vs 铁矿空 等）：
   → 相关性高 ≠ 价差一定回归，基差风险始终存在
   → 对冲单必须设价差止损（如价差偏离均值 ±2σ 离场），不能"只对冲不止损"
4. 基差规则：基差 = 现货价 − 期货价
   基差走强（现货强于期货）→ 现货市场偏紧，期货贴水 → 多头友好
   基差走弱 → 现货偏弱，期货升水 → 空头友好
```

### F. 交易时段与手续费规则
```
1. 交易时段：日盘 09:00-15:00（分节）+ 夜盘（各品种不同）
   有夜盘：贵金属/有色/原油/黑色/部分化工（21:00-次日02:30不等）
   无夜盘：大部分农产品（豆粕/玉米/白糖等，21:00-23:00或无）
2. 夜盘跳空 → 隔夜单风险主要在夜盘，21:00 前检查持仓
3. 平今手续费差异：
   部分品种平今仓手续费远高于平昨（如股指平今=平昨15倍、螺纹平今免收）
   → 日内频繁往返的成本必须计入策略，高频日内默认不适用该规则集（用专用day-trade规则）
```

## 例外处理
- **套保单（有现货/订单对冲）**：仓位上限放宽至 5-8 倍杠杆，但必须有现货对应凭证，且标注"套保"；无凭证的"伪套保"按投机单管理
- **程序化/高频日内**：本规则集的隔夜/仓位铁律不适用，改用专用日内规则（手续费敏感、单笔止损固定、无隔夜）
- **股指期货（金融组）**：与股票 Research OS 联动——股票侧🔴信号（kh_stock_rules_002 七类信号）count>=4 时，股指期货单禁止新增多头，已有多头减半
- **期权替代**：高波动预期（VIX/隐波高位）时，用买入期权替代裸期货多头（损失有限=权利金），作为降杠杆手段

## 失败边界
- **此方法不适用于**：无夜盘品种的纯高频策略（本规则假设持仓过夜场景）；商品现货贸易商的期现套利（需要基差套保模型，非本规则集）
- **仓位铁律在极端单边行情下失效**：连续涨跌停时，即使仓位合规（20%）也会因无法平仓+扩板放大亏损——仓位规则管"平时"，极端行情靠"第一时间处理+不摊薄"
- **成功率**：常规行情下，严格执行仓位铁律可将"单次爆仓概率"压到 <1%（杠杆≤3倍+50%总占用上限）；但无法防住黑天鹅（如2020年4月原油负价格）——负价格事件中任何多头仓位规则都失效，唯一解是"该品种负价历史提醒+流动性极差品种禁隔夜"
- **已知盲区**：保证金比例是变量不是常量——交易所临时上调保证金（节假日/波动率飙升）会让"看似合规"的仓位一夜之间变成超仓，所以规则B要求每日试算，不能按开仓时的比例一劳永逸
