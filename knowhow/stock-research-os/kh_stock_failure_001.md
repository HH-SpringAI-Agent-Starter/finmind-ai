## 失败案例A：首启动追涨（华微电子6/4）

### 场景
2026年6月4日，华微电子突破+6.62%，选股引擎推荐

### 决策流（错误判断）
```
1. 放量突破 ✅
2. 技术形态突破 ✅
3. 板块有热点 ✅
→ 推荐买入
```

### 实际结果
- 推荐后次日（6/5）全球暴跌，华微电子跟跌
- 用户亏损
- 教训：**突破日推荐时必须标注热闹风险**

### 归因
| 判断 | 正确做法 |
|------|---------|
| 只看突破形态 | 还要看大盘环境（当天纳指期货已跌1.5%） |
| 没提示风险 | 突破日仍可推荐但必须降一档优先级 |
| 没标注⚠️ | 必须标注"当前热闹+大盘不稳，等回踩再入" |

## 失败案例B：数据新鲜度血案（永鼎6/11）

### 场景
2026年6月11日写日报时查永鼎股份涨跌

### 决策流（错误判断）
```
用web_search查股价 → 看到"永鼎 -8.08%" → 
以为是6/11实时数据 → 写进日报
```

### 实际结果
- web_search返回的是6/10东方财富缓存页面（T-1数据）
- 永鼎6/11实际是+0.06%
- 还漏了太极实业涨停（+9.99%）
- 影响当日持仓决策

### 根因
```
搜索引擎 publishedDate 不可靠
→ 缓存页面publishedDate与实际不符
→ 误把T-1当T日数据
```

### 铁律
```
所有A股股价/涨跌幅必须走腾讯实时API(http://qt.gtimg.cn/q=)
绝对禁止用web_search查股价
定时任务产出股价仅作初筛参考，输出前必须用API重新拉一遍
输出前的第一步就是跑API脚本
```

## 失败案例C：六氟化钨（WF6）接盘

### 场景
2026年6月4日 WF6板块涨停（多只），6月10日才识别

### 错误决策链
```
6/4 板块涨停 → 未触发涨价链拆分
6/5-6/9 持续上涨 → 未触发
6/10 才识别 → 已涨50%+
→ 从发现到买点，晚了6天
→ 接盘位置，回撤-25%
```

### 归因
| 问题 | 正确做法 |
|------|---------|
| 板块涨停未触发拆分 | >3只同板块涨停触发涨价链拆分 |
| 涨价消息没当天捕获 | 每一条涨价消息都必须当天捕获+拆分 |
| 龙头在688就放弃 | 龙头在科创板≠主板没标的 |
| 六氟化钨龙头中船特气688146 | 漏查#2昊华科技600378（翻倍） |

### 铁律
```
查到龙头后必须继续查行业#2#3是谁、在哪个板块
主板有没有替代标的，漏查一步=可能错过翻倍机会
```

## 失败案例D：脑机接口漏信号（创新医疗7/1）

### 场景
2026年6月28日（周日），创新医疗子公司赛博灵科AM5获二类医疗器械注册证

### 错误决策链
```
6/28（周日）博灵脑机发公告获注册证 → 属🔴A类价值拐点信号
6/29（周一）系统未触发拆分 → 无人处理
6/30（周二）仍未处理
7/1（周三）创新医疗涨停+10% → 才知道
→ 再追已是高点
```

### 归因
| 问题 | 根因 | 修复 |
|------|------|------|
| A类信号无扫描 | 只关注涨价信号 | 增加ABCDEFGH八类事件扫描 |
| 周末公告被忽略 | 定时任务周中才跑 | 周末公告也要扫描 |
| 无"技术突破→注册证→商业化"链意识 | 缺乏商业化拐点识别 | 注册证获批等同涨价信号优先级 |

### 触发规则更新
```
A类·价值拐点信号（遗漏高发区）:
- 医疗器械/药品获注册证
- 技术原型→商业化（实验室到量产）
- III期临床成功
- 首条产线投产/首台套交付
- 产品通过大客户验证
```

## 失败案例E：量化时代卖出不及时（6/26血案）

### 场景
2026年6月25日隔夜美股：纳指仅-0.46%，但苹果-6%、微软-3%、亚马逊-3%、Meta-2%、黄金破4000、比特币破6万、中概-2.74%

### 错误决策链
```
只看纳指跌>3%单一阈值 → 纳指仅-0.46% → 判定"安全"
→ 6/26 A股开盘创业板-2.58%，4500+下跌
→ 未提前预警 → 严重失职
```

### 归因
| 维度 | 错误 | 修复 |
|------|------|------|
| 信号覆盖 | 只看单纳指 | 七类信号全量扫描 |
| 加权判断 | 单一阈值 | ≥4个🔴即视为等同于纳指跌>3% |
| 量化认知 | 等确认信号 | 量化不给你确认时间，信号出→卖 |

### 七类🔴信号清单
```
①纳指跌>2%
②科技七巨头≥3只跌>3%
③黄金单日跌>2%破整数关口
④比特币单日跌>5%
⑤VIX涨>20%
⑥中概金龙指数跌>2.5%
⑦WTI原油单日跌>3%
```

### 量化时代核心认知
```
"第一时间都跑不掉，所以必须在第一时间跑"
不仅仅是推送预警→而是直接触发卖出管线执行卖出
不等14:30，不等下一轮巡检，不等确认
```

## 失败案例F：艾艾精工摘帽急拉遗漏

### 场景
艾艾精工摘帽后5天内涨停，未触发最高优先级买入

### 错误
```
摘帽+急拉涨停 = 三重共振暴击
但系统中没有专门的摘帽急拉识别模块
→ 错过了翻倍机会
```

### 修复
```
摘帽30天内+急拉涨停 → 🚨 S级中的S级，独立于三源分类
→ 立即QQ邮箱推送
→ 参考案例：华微电子摘帽当日涨停→翻倍
            艾艾精工摘帽5天涨停→连板翻倍
```
