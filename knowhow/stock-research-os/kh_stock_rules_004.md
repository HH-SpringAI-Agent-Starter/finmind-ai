## 期货研究方向业务规则（四大天王选品·入场区间·条件单体系）

> 与 kh_stock_rules_003（期货风控与交易侧）互补：**第3块管"开了仓之后怎么活"，本块管"开仓之前怎么选、等什么价位、什么信号才动手"**。研究侧的核心矛盾不是方向对不对，而是**大部分时间应该什么都不做**——四大天王的实战记录里，连续多日四候选全部高于入场区间，正确的动作只有一个：不追。规则的执行率 = 空仓纪律的坚持率。

## 场景
- Research OS 每日盘前（默认 07:00-07:30）四大天王开仓条件巡检
- 新品种纳入候选池时的资质审核
- 候选品种价格进入/偏离入场区间的持续跟踪
- 开盘后对盘前预案的按实际开盘价复核（09:00 条件单）

## 输入
1. 前日夜盘收盘价 + 当日晨间开盘前情报（05:00 前后）
2. 四大天王候选池：品种名单 + 各自入场区间（低-高双边界）
3. 各品种一手保证金、合约乘数、最新价格
4. 账户权益、当前持仓、冻结保证金、保证金率
5. 历史台账（futures_tracker）与模拟盘实际持仓（broker）——两者必须比对

## 决策流

### A. 候选池管理规则（先定池子，再谈价格）
```
1. 四大天王候选池 = 当前主线品种（如 EG乙二醇/SI工业硅）+ 历史备选（如 SC原油/SN沪锡）
2. 新品种入池三审：
   ① 流动性：主力合约日均成交额 ≥ 5亿元（冷门品种禁入）
   ② 逻辑性：有可复述的供需/库存/基差逻辑（说不清逻辑=不纳入）
   ③ 保证金可承受：一手保证金 ≤ 总权益 × 20%（超铁律的品种即使回踩区间也不开，
      历史上 SC 58,780元占权益52.8%、SN 51,152元占45.9% → 双双禁开）
3. 池子维护：每日巡检时全部候选逐一核对"最新价 vs 区间"，哪怕不操作也必须记录判定
```

### B. 入场区间判定（追高铁律——最高优先）
```
对每个候选品种：
  最新价 < 区间下限 → 低于区间 = 超跌候补，等企稳信号（不直接接飞刀）
  最新价 ∈ [下限, 上限] → 区间内 = 可开仓窗口 ✅
  最新价 > 区间上限 → 高于上限 = 追高 → 一律不追 ❌

追高判定分级：
  超上限 < 3%   → 高挂观察，回踩即触发条件单
  超上限 3-10%  → 强不追，标注"严重追高"，当日排除
  超上限 > 10%  → 直接排除出当日候选（历史：EG +12.3%/SC +13.7% 均为"严重追高"）

核心铁律：候选高于区间上限=不追涨，无论逻辑多强。
实战证据：2026-08-24/08-25 连续两日四候选全部高于上限 → 决策均为"无新开仓"。
```

### C. 条件单编制规则（盘前预案 → 开盘复核 → 触发执行）
```
1. 盘前（07:00-07:30）先写预案：给每个可能回踩的品种预设条件单
   格式：品种 | 触发条件（价格区间+企稳确认）| 开仓量 | 止损 | 止盈
2. 开盘（09:00）按实际开盘价复核：预案价格不再有效 → 用开盘价重算区间
3. 触发条件必须含"企稳确认"，禁止开盘价直接进场：
   例：JD鸡蛋 开仓条件 = 开盘3750-3780 且 30分钟内缩量企稳不再破3750 → 轻仓试多1手
       破3750 → 放弃（条件不成立就空仓，不将就）
4. 条件单开仓量按保证金占比控制：
   轻仓试多 = 保证金占用 ≤ 2% 总权益（JD 1,894元 ≈ 1.7%）
   标准开仓 = 保证金占用 4-5% 总权益（EG/SI 2手 ≈ 4-4.5%）
5. 每个条件单必须带止损价 + 止盈价（止损 3720 / 止盈 3980 类，先定再开）
```

### D. 持仓管理预案规则（与开仓预案同表输出）
```
1. 每日巡检持仓，三态分类：
   已达止盈目标 → 开盘按目标区间离场（HC：目标3320-3340 → 开盘3320-3360止盈）
   持有推进     → 定保护位 + 冲高分批减半（CU：保护107,500，冲108,500+减半）
   跌破保护位   → 开盘不能快速收复则全平（M：保护3220，夜盘收3218 → 开盘复核）
2. 保护位规则：保护位 = 浮盈回吐阈值，跌破即执行，不赌反弹
3. 分批止盈规则：目标区上沿分批（如 3260-3280 分批止盈），不追求卖在最高
4. 盈利持仓保护位随价格上移（移动止盈），但每日只在盘前重算一次，盘中不频繁改
```

### E. 数据一致性与台账同步规则（防"假空仓"陷阱）
```
1. 每次巡检必须比对两个数据源：
   模拟盘实际持仓（broker） vs 历史台账（futures_tracker）
2. 不一致时以 broker 为准，台账标注差异：
   历史案例：台账记 HC 2手，broker 实际 1手 → 不影响当日决策但必须记录注明
3. 保证金率监控：保证金率 = 冻结保证金 ÷ 总权益
   < 80% → 合规
   ≥ 80% → 强平风险区，禁止一切新开仓
   ≥ 54% 警戒线（账户特定）→ "只守不加"，停止一切新开仓（历史：53.8-54.8% 触发）
4. 非交易时段（07:00 盘前）引擎强制拦截交易指令：
   盘前只能生成预案/条件单，实际下单只能在 09:00 后按复核价执行
```

### F. 研究侧定性规则（什么算"值得研究"）
```
1. 一个品种值得研究的门槛：
   ① 有供需缺口/库存拐点/基差极端值的可量化证据
   ② 与主线（宏观/地缘/产业周期）有因果链，不是纯消息驱动
   ③ 价格处于历史区间 20%-80% 分位（极端高低位都不是好研究标的）
2. 研究输出必须带：方向判断 + 入场区间 + 止损止盈 + 失效条件（四个齐了才算完成）
3. 没有失效条件的研究 = 未完成研究：开仓前必须写清"什么情况证明我错了"
```

## 例外处理
- **消息面重大变化（如地缘升级导致原油跳空）**：入场区间失效 → 当日锁仓不追，等 1-2 个交易日重新定价后重算区间，不按旧区间挂单
- **品种长期偏离区间（>10% 持续一周）**：说明区间本身过时 → 重估基本面重写区间，而不是硬等回踩（等待成本也是成本）
- **持仓浮盈大但未达目标**：允许用"冲高减半"替代"到点全平"，但减半后剩余仓位保护位上移
- **账户保证金率 > 80%**：无视一切开仓预案，先降仓——生存优先级 > 机会优先级

## 失败边界
- **此方法不适用于**：日内高频/波段短线（本规则假设日线级持仓、盘前一次性决策）；纯技术面交易者（本体系以基本面+区间为核心）；无主力合约的冷门品种（流动性不足时区间无意义）
- **区间策略的固有弱点**：价格可能永远不回到区间（踏空）——历史真实代价：EG/SI 连续3周高于区间，整个周期零开仓。**踏空不是失败，追高才是失败**，这是本规则的核心立场
- **条件单失效场景**：开盘跳空高开直接越过区间（企稳确认来不及发生）→ 放弃该日机会；涨停/跌停无法成交 → 按第3块规则C处理（不赌次日）
- **成功率**：按区间+企稳确认开仓，入场后 1:2 盈亏比以上胜率 ~60-65%（基于用户2026-07以来近15次条件单执行记录回看）；代价是开仓频次极低（月度个位数），大部分时间空仓
- **已知盲区**：区间边界是静态的，遇到趋势加速段（单边市）会系统性踏空；且模拟盘与真实盘滑点/成交差异未纳入校验——代码化时（子任务D）需加入"滑点预算 + 区间动态修正"两参数
