## A股选股业务规则

### 1. 来源优先级规则（选股权重排序）

核心10源按权重从高到低：

| 优先级 | 来源 | 权重 | 说明 |
|--------|------|------|------|
| P1 | 闷声涨×3 | 3.0 | 连续3天温和放量上涨，无媒体关注 |
| P2 | 涨价逻辑×3 | 3.0 | 卡脖子环节涨价，供给刚性+需求拉动 |
| P3 | 产业链传导 | 2.8 | BOM拆解+七步推导的上游受益环节 |
| P4 | 概念动量 | 2.5 | 同概念≥3只连续3天放量，有连板梯队 |
| P5 | 板块抗跌 | 2.5 | 大盘下跌时板块逆势/抗跌 |
| P6 | 趋势回调 | 2.0 | 强趋势→深度回调→缩量企稳→放量回升 |
| P7 | 横盘起量突破 | 2.0 | 横盘≥60天+振幅15-45%+放量突破 |
| P8 | 人气排名 | 1.5 | 问财/东方财富人气TOP10 |
| P9 | 卡脖子技术突破 | 1.5 | 技术突破+国产替代+认证进展 |
| P10 | 消息催化 | 1.0 | 公告/新闻/事件驱动 |

**多源共振规则**：≥2个核心源同时覆盖→自动升级特别推荐

### 2. S级判定规则

满足任一即入S级池：
- **S级B·产业链**：七步推导完成+利润池最大环节确认+多因子共振
- **S级C·横盘起量**：底部横盘≥60天+放量涨停/起量加速
- **S级A·急拉**：急拉涨停+产业逻辑共振
- **S级BC·双重共振**：S级C + S级B产业逻辑 = 最高确定性

### 3. 选股四维度框架（判断质量）

| 维度 | 一句话 | 对应体系 |
|------|--------|---------|
| ①第一次涨价/卡脖子 | 首次出现=信息差红利窗口，3-7天过期 | price_signal_capture |
| ②ST摘帽 | 摘帽30天内=黄金窗口，摘帽+涨停=S级中的S级 | st_delist_analysis |
| ③涨停抓取 | 三种模式(宝鼎/墨龙/纸业)，涨停不追等回踩 | three_limit_up_modes |
| ④趋势3天 | 连续3天走强=动能确认，第3天是关键 | 趋势回调体系 |

### 5. 仓位规则（分层管理）

```
中线24万：
  单品种 ≤ 25%
  总仓位 ≤ 80%
  止损按产业逻辑而非固定金额

短线2万：
  单品种 ≤ 25%
  总仓位 ≤ 80%
  单次止损 ≤ 400元（-3%）

隔夜超短：
  14:50-14:55买
  次日9:30-10:00冲高卖
  单只≤5%
  止损-3%
```

### 6. 期货六因子规则

| 因子 | 指标 | 方向判断 |
|------|------|---------|
| 库存 | 社会库存/仓单 | 去库=利多，累库=利空 |
| 开工率 | 产能利用率 | 开工率下降=供给收缩=利多 |
| 利润 | 加工利润/盘面利润 | 利润低位=减产预期=利多拐点 |
| 基差 | 现货-期货 | 正基差=期货低估，负基差=期货高估 |
| 月差 | 近月-远月 | Back=紧缺，Contango=宽松 |
| 供需缺口 | 表需-产量 | 缺口扩大=趋势性行情 |

### 7. 标签规则（所有输出必须标注）

- 💼 用户持仓（7只固定池）
- ⭐ 日频S级关注（三源分类）
- 💎 低位潜伏池（10只+）
- 🔍 系统推荐（引擎/拆解/量化）
- 📊 被动扫描（材料/板块/卡脖子）
- 🟡 降级观察（逻辑待验证）

### 8. 输出格式规则（四段式）

```
第一段：期货端 — 有无直接/间接期货合约+映射路径
第二段：A股四梯队 — 🥇核心→🥈供需缺口→🥉全产业链→🏅转型催化
第三段：对比速查表 — 梯队/代码/名称/弹性来源/确定性
第四段：风险+待跟踪 — 追高风险/排除过滤/业绩风险
```
