## 期货四大天王·专家决策路径（开仓前怎么做判断）

> 与 kh_stock_rules_004（期货研究方向业务规则）配套：规则管"什么能做、什么不能做"，本块管**专家大脑里每一层判断怎么走、为什么这么走、什么时候推翻规则自己拿主意**。核心立场：期货侧90%的时间正确动作是"什么都不做"——决策路径的价值不在"多开仓"，而在**让每一次开仓都经过同一套心理安检，且安心接受空仓**。

## 场景
- 每日盘前（07:00-07:30）对四大天王候选池逐一过安检
- 候选品种价格进入/贴近入场区间的当日（09:00 条件单复核时）
- 持仓品种出现浮盈冲高/跌破保护位的盘中时刻
- 新品种第一次纳入池子时的"专家直觉校验"（规则之外的判断层）

## 输入
1. 四大天王候选池 + 各自入场区间（低-高双边界）
2. 最新价 vs 区间位置（低于/区间内/超上限及超幅百分比）
3. 昨夜盘收盘表现 + 晨间情报（05:00 futures_preopen）
4. 持仓三态（已达止盈/持有推进/跌破保护）+ 账户权益与保证金率
5. 品种自身的供需/库存/基差证据链（可复述的逻辑）

## 决策流

### 第一层：选的不是品种，是"现在该不该出手"

```
对每个候选品种，先回答三个问题（回答顺序固定，先答后动）：
Q1 逻辑还在吗？      → 供需/库存/基差证据链今天是否仍成立（成立=候选资格保留）
Q2 价格在区间吗？    → 低于/区间内/超上限（区间判定=唯一入场门票）
Q3 保证金扛得住吗？  → 一手保证金 ≤ 总权益×20%，且账户保证金率 < 54%警戒线

三问全过 → 进入第二层安检
任一不过 → 该品种今日不动作（Q1不过=剔除出池，Q2不过=等，Q3不过=生存优先）
```

专家为什么这么判断：**方向对 ≠ 能开仓**。四大天王的实战教训是"看对的品种因为仓位超限/价位错位而亏钱"，所以判断顺序必须是"逻辑→价格→仓位"三层安检，而不是"看好就开"。Q1 过滤掉过时逻辑（避免为旧故事买单），Q2 过滤掉冲动（避免追高），Q3 过滤掉生存风险（避免爆仓）——三层各管一类死法。

### 第二层：区间内也不立刻开——"企稳确认"的专家判定

```
价格 ∈ [下限, 上限] 时，专家不直接进场，走企稳确认链：
1. 开盘价在区间内？    否 → 用开盘价重算区间，预案作废（规则C）
2. 30分钟内是否缩量企稳？  否 → 放弃该日机会，不将就
3. 企稳形态的二选一判定：
   a. 缩量横盘贴着区间下沿 → "试多"信号（轻仓 保证金≤2%权益）
   b. 放量上攻突破区间中轴 → "标准"信号（标准仓 保证金4-5%权益）
   c. 放量下破区间下沿     → 反向看待：等新的企稳，不接飞刀
4. 触发前必须已挂好止损+止盈（先定再开，无止损不开）
```

专家为什么这么判断：**开盘价是最新的市场共识，盘前预案只是预判**。用"30分钟缩量企稳"代替"开盘直接进"，是为了把"市场开盘冲动价"过滤成"市场认可价"——历史执行中，直接开盘进场的单子大多吃开盘瞬间的假突破；等企稳后的进场点更靠近真实方向。缩量=分歧减少=方向被确认，放量上攻=资金表态。

### 第三层：追高的心理安检（追高铁律的内心戏）

```
最新价 > 区间上限时，专家不是简单"不买"，而是走追高三级判定：
 超上限 < 3%  → 高挂观察：写条件单等回踩，忍住不手动追（想追时念：8/24、8/25 四候选全超上限，空仓是对的）
 超上限 3-10% → 强不追：当日排除，标注"严重追高"（研究笔记里记一笔，防止盘中被情绪卷进去）
 超上限 > 10% → 直接出池：当日候选剔除（历史 EG +12.3% / SC +13.7% 皆是坑）

判定完成后的固定动作：
  → 在当日纪要里写"今日无新开仓 + 原因"，把空仓变成可追溯的决策而不是"没顾上"
```

专家为什么这么判断：**追高的代价不是"买贵了"，是"买在了逻辑兑现的末端"**。品种超上限意味着市场已经把逻辑 price in，此时进场的期望收益为负（接盘概率大）。空仓不是失败——踏空只是少赚，追高是真亏。写"无新开仓"记录是为了对抗"手痒"，把纪律显性化。

### 第四层：持仓三态的盘中专家处理（与开仓预案同表）

```
对每个持仓，开盘先分类，再按类处理：
 态1 已达止盈目标 → 开盘按目标区间离场（不等更高，分批：目标区上沿分批离，不追求卖最高）
 态2 持有推进     → 定保护位（浮盈回吐阈值）→ 冲高分批减半（冲高即兑现一半，剩余保护位上移）
 态3 跌破保护位   → 开盘不能快速收复 → 全平，不赌反弹（夜盘收破 → 次日开盘复核，破位即执行）

盘中特例（专家可动用）：
  a. 浮盈大但未到目标 → 用"冲高减半"代替"到点全平"（减半后剩余保护位上移）
  b. 消息面重大变化（地缘/政策） → 当日锁仓不追，等 1-2 日重新定价后重算区间
  c. 保证金率 ≥ 54% → 只守不加，一切开仓预案作废（生存优先级 > 机会优先级）
```

专家为什么这么判断：**盈利单的处理比亏损单重要**。亏损单靠止损（规则），盈利单靠"让利润奔跑但锁住回吐"——保护位+分批离场是唯一能让盈亏比稳定在 1:2 以上的机制。盘中频繁改保护位是亏损主因，所以保护位每日盘前只重算一次，盘中不手痒。

## 例外处理
- **规则与直觉冲突时（罕见但有）**：区间判定通过但专家直觉强烈不适（如流动性骤变、关联品种异动）→ 按"降半档"处理：原计划标准仓改为轻仓试仓，保留后续加码权利；直觉不适但说不出理由时，宁可错过
- **长假前（春节/五一/十一）**：即使一切安检通过，节前 ≤3 个交易日不留重仓过夜（可用资金 < 总权益10% 则清仓）——跳空风险 > 机会，交易所同时会上调保证金
- **两个候选同时通过安检**：选"逻辑证据链更完整"那个，不选"价格更接近区间"那个（价格会变，逻辑是根）；同组品种方向一致时优先（组内共振，可信度+20%）
- **开盘跳空直接越过区间**（低开破位/高开超限）：当日该品种放弃，企稳确认来不及发生；跳空日不做任何开仓（跳空=市场已表态，等重定价）

## 失败边界
- **此方法不适用于**：日内高频/波段短线（本决策流假设日线级持仓+盘前一次性决策）；纯技术面交易（本路径以基本面证据链+价格区间为核心）；新品种无历史数据者（区间无锚，判定失效）
- **踏空是固有代价**：价格长期高于区间时（EG/SI 曾连续3周超区间），整套路径输出为"持续空仓"——此时决策正确但不赚钱，需要心态建设：**踏空不是失败，追高才是失败**
- **区间静态盲区**：单边趋势加速段（趋势市）中，价格永远在区间上方，本路径会系统性踏空趋势——已知盲区，代码化时（子任务D）需加"区间动态修正"参数
- **成功率**：按"三层安检+企稳确认+止损止盈先行"执行，入场后 1:2 盈亏比以上胜率 ~60-65%（2026-07 以来近15次条件单执行回看）；代价是开仓频次极低，月度个位数
- **不可验证项**：企稳确认的"缩量"阈值是经验值（当前未量化），不同流动性品种应不同——这是子任务D代码化时最需要参数化的点
