## S级全回测·涨跌归因决策流

### 触发器
每天21:00，对S级A/B/C/BC四源全覆盖，每只逐只归因

### 决策流

```
输入：S级关注池（所有标的）

for each 标的:
  1. 获取今日涨跌幅
  2. 检查逻辑状态:
     a. 核心涨价品种价格从高点回撤>15%? → 🚨强制降🟡观察
     b. 天量换手>10%+主力净流出连续2天? → 🚨当日开始减仓
     c. 板块异动公告密集+散户涌入? → 🚨脉冲即将结束
     d. 以上皆否 → 继续持有，启动每日逻辑验证

3. 逻辑状态六档:
   ✅ 强化（跌但逻辑更强=买点）
   ⚠️ 持稳
   ⚠️ 待验证
   ❌ 反转（降级）
   ⏰ 72h（地缘类时效标记）
   ⚠️ 背离预警（价格跌股价未跌=最危险信号）

4. 跌的S级必须六维度分析:
   ①今天为什么跌
   ②核心逻辑还在吗
   ③短期回踩vs逻辑反转
   ④历史同类反弹周期
   ⑤到买点了吗
   ⑥大盘影响

输出：每日S级池异动归因表
```

## 涨价信号捕获→拆分决策流

### 触发器
任何渠道看到涨价消息，当天捕获+拆分，不等定时任务

### 五阶段模型决策流

```
阶段①发现期(识别):
  - 涨价幅度>30%(单月)+库存方向确认(去库) → ⭐S级
  - 涨价幅度>50%+供给缺口+壁垒 → ⭐S级最高
  - 涨价幅度<30%但有地缘催化 → 🟡观察等确认
  - 涨价但无瓶颈环节 → ⚠️不进S级

阶段②爆发期(确认):
  - 三分法归类: 🔴大宗/🟡加工组件/🟢技术稀缺品
  - 四问判断: 需求拉or供给推? 有无瓶颈? 宏观敏感? 库存方向?
  - 瓶颈环节定位 → 利润池最大 → 优先推荐
  - A股主板映射 + S级判定

阶段③主升浪(持有):
  - 继续持有，每日验证逻辑
  - 跟踪价格、库存、开工率

阶段④背离期(预警):
  - 价格从高点回落>15%+股价仍在涨=严重背离→强制降级
  - 天量换手(>10%)+主力净流出=见顶概率>70%

阶段⑤退潮期(退出):
  - 涨价类S级在阶段③结束后最长持有≤7个交易日
  - PRICE回撤确认后股价滞后约7-14天见顶
  - 回撤-25%~-30%是常见幅度
```

### 退出三条件（任一触发即执行）

```
条件A: 核心涨价品种价格从高点回撤>15%
条件B: 天量换手(>10%)+主力净流出连续2天
条件C: 板块情绪过热(多只发异动公告+散户大量涌入)
```

## 量化时代·系统性风险卖出决策流

### 触发器
七类🔴信号中≥4个同时触发

### 信号清单
```
①纳指跌>2%
②科技七巨头≥3只跌>3%
③黄金单日跌>2%破整数关口
④比特币单日跌>5%
⑤VIX涨>20%
⑥中概金龙指数跌>2.5%
⑦WTI原油单日跌>3%
```

### 决策流
```
累计≥4个🔴:
  → 07:00预警含"⚠️今日高风险，建议减仓"
  → 09:25开盘后每30分钟推送一次实时跌幅

累计≥5个🔴:
  → 07:00直接建议开盘减仓至≤30%
  → 14:30前必须推送卖出提醒

量化驱动信号（如Meta卖算力等）:
  → 不等确认，信号出→卖
  → 第一时间都跑不掉，所以必须在第一时间跑
```

## 底部横盘涨停（S2a）决策流

### 识别条件
- 横盘≥60天（振幅15-45%）
- 分钟级加速+1.5%以上
- 量比>2x
- 离涨停价距离<10%

### 决策流
```
1. 识别到S2a信号 → 立即推送，不等定时任务
2. 标注🔴 S级紧急
3. 涨停是启动信号→次日回踩才是买点
4. 如果同时有产业逻辑共振 → 升级为⭐S级BC·双重共振
```

## 摘帽+急拉涨停决策流

### 触发条件（ALL必须同时满足）
- 近30天内撤销*ST
- 今日出现急拉涨停（盘中+9.9%+）
- 主板标的
- 流通市值<100亿

### 决策流
```
满足全部4条 → 🚨 S级中的S级，独立于三源分类之外
摘帽5天内涨停 → 严重最高优先级
→ 立即通过QQ邮箱推送
→ 同时追加到⭐S级A·急拉（标注🚨摘帽急拉）
→ 买入建议：次日回踩是买点
```
