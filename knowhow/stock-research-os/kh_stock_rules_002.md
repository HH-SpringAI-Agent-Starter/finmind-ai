## 量化时代·风险卖出与资金虹吸业务规则（卖出侧）

> 与 kh_stock_rules_001（买入侧）互补。买入侧决定"买什么"，本规则决定"什么时候必须跑、为什么跑、跑到什么仓位"。**量化市场里，跑得快比跑得准重要——量化没有情绪，风险信号一出它第一时间砸盘，散户没有确认的时间。**

## 场景
- 任何时间看到风险信号（盘中/盘前/隔夜）
- 每日 07:00 晨间预警、09:25 开盘、盘中每30分钟巡检
- 单一板块成交异常放大、大赛事/大IPO临近
- 持仓股所属涨价品种价格异动

## 输入
1. 隔夜美股：纳指涨跌幅、科技七巨头（苹果/微软/亚马逊/Meta/谷歌/英伟达/特斯拉）个股涨跌
2. 黄金/比特币/VIX/WTI 价格变动
3. 中概金龙指数、A股前日收盘情绪
4. 板块成交占比、主线内卷信号
5. 持仓股核心涨价品种价格走势

## 决策流

### A. 七类🔴信号判定（任一触发=1个🔴）
```
1. 纳指跌 > 2%                                  → 🔴
2. 科技七巨头 ≥3只跌 > 3%                       → 🔴
3. 黄金单日跌 > 2% 且破整数关口                 → 🔴
4. 比特币单日跌 > 5%                            → 🔴
5. VIX 涨 > 20%                                 → 🔴
6. 中概金龙指数跌 > 2.5%                        → 🔴
7. WTI原油单日跌 > 3%                           → 🔴
```

### B. 累计信号分级响应（核心决策流）
```
count = 累计🔴数量

count >= 5 → 07:00 直接建议开盘减仓至 ≤30%
            + 14:30 前必须推送卖出提醒
            → 09:25 开盘后每30分钟推送实时跌幅
            → 信号出→直接触发卖出管线执行卖出（不等确认）

count >= 4 → 07:00 预警必含"⚠️今日高风险，建议减仓"
            + 09:25 开盘后每30分钟推送一次实时跌幅

count >= 1 → 常规风险提示，标注影响板块
count == 0 → 正常操作
```

### C. 全球暴跌强制卖出铁律（最高优先级）
```
触发：A股开盘前确认全球风险资产恐慌（B级 count>=4 或 纳指跌>3%）
执行：14:30 前必须推送卖出提醒——宁可错卖不可晚卖
     优先级高于一切其他监控任务（高于日报/选股/回测）
     不等收盘后日报才报，盘中确认暴跌立刻推
```

### D. 涨价类S级退出三条件（任一触发即执行退出）
```
1. 核心涨价品种价格从高点回撤 > 15%
   （价格跌、股价未跌 = 最危险背离信号）   → 强制降🟡观察 + 减仓
2. 天量换手 > 10% + 主力净流出连续2天      → 当日开始减仓
3. 板块情绪过热（多只发异动公告 + 散户大量涌入）→ 脉冲即将结束，减仓
```

### E. 资金虹吸效应判断（池子里还有多少水）
```
六大虹吸源（任一出现=水被抽走）：
  ① 大赛事（世界杯/欧洲杯/奥运）    ② 大型IPO
  ③ 跨市场（港股/美股/加密热）      ④ 板块虹吸（主线成交>15%）
  ⑤ 政策吸金（国债/正回购）         ⑥ 日历效应（春节/季末/长假）

判断标准：
  单一板块成交占全市场 > 12%  → 虹吸开始
  主线内卷（龙头涨跟风跌）    → 虹吸到顶，减仓信号

应对：
  虹吸期   → 减仓高估值成长股 → 转防御（高股息/大市值）
  无虹吸期 → 正常操作
```

## 例外处理
- **消息面小作文驱动**：不要求价格确认，信号出即卖（量化先砸盘，散户跑不掉）
- **持仓中逻辑仍硬的S级**：单日下跌≠逻辑失效，先用六维度归因（为什么跌/逻辑还在吗/回踩vs反转/历史反弹周期/到买点了吗/大盘影响），只有逻辑状态反转（❌）才降级；但**系统性风险（B级 count>=4）不适用此例外，一律先卖**
- **地缘类信号**：标注"⏰72h复验"，72小时内重新验证逻辑是否仍成立
- **媒体二次刷屏（3-6个月后炒冷饭）**：是接盘信号不是信息差红利——降级🟡观察，标注"⚠️媒体过热，散户接盘风险"。消息首次曝光1-3天内才是红利窗口

## 失败边界
- **此方法不适用于**：非系统性风险的个股波动（单只票跌但大盘稳、板块稳→正常回踩，用趋势回调体系等企稳，不触发卖出）
- **不适用于**：长线价值仓（廖小爱三高框架标的）——短线卖出规则与长线持有逻辑冲突时，长线仓按产业逻辑止损，不按🔴信号割肉
- **成功率**：系统性风险识别率 ~85%（六类🔴多信号共振法，6/25血案后验证）；代价是误报率约15%——宁可错卖不可晚卖，误报的损失 < 漏报的损失
- **已知盲区**：单看纳指一个指标会漏掉结构性恐慌（6/25纳指仅-0.46%但四重🔴共振→次日创业板-2.58%）——所以必须用七类信号累计，不用单一阈值
